# Changelog

## [0.1.0] - 2026-11-18
### Added
- Базовий синтаксис та парсер (Lark) для мови SIPL.
- Інтерпретатор з підтримкою змінних, арифметики, умов (if) та циклів (while).
- CLI-інтерфейс для запуску та отримання JSON-трасування (Trace).
- Повноцінний DAP-сервер (Debug Adapter Protocol).
- VS Code Extension з підтримкою покрокового відлагодження (Breakpoints, Step Over, Variables).
- Набір із 20 тестів (позитивних та негативних) для перевірки граматики.
